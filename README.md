# 🍜 Oodles of Noodles - Data Analysis Dashboard 📊


🔗 **[View the Live Power BI Report](https://ammar1122-lg.github.io/Az_Portfolio/)**  

Welcome to the **Oodles of Noodles** Power BI Project – a flavorful journey into business intelligence using real-world inspired data from a fictional noodle restaurant chain. This interactive report highlights deep insights into sales, customer behavior, and operational trends, designed to help stakeholders make data-driven decisions.

---

## 📌 Project Overview

The goal of this project was to analyze key performance indicators (KPIs) for the **Oodles of Noodles** brand and provide a dashboard that helps track performance across:

- 📈 Sales Performance
- 🛍️ Product Trends
- 🧑‍🤝‍🧑 Customer Demographics
- 📍 Regional and Outlet-Wise Comparisons
- ⏰ Time-Based Insights

---

## 🧠 Key Insights & Findings

- The most profitable products and regions
- Peak sale periods and customer purchase habits
- Outlet-level performance variation
- Customer segment preferences
- Revenue trend forecasts

---

| Tool          | Description                                   |

## 📊 Dashboard Features

- Interactive slicers (region, date, outlet, etc.)
- Drill-down capabilities for detailed analysis
- KPI cards for at-a-glance performance
- Custom visuals for product-wise breakdown
- Responsive design with dynamic filtering
